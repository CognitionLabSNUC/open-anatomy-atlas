# Changelog

## 0.0.1 (first public release)

Open Anatomy Atlas, developed by the Cognition Lab.

- Interactive 3D atlas: rotate, zoom, click to identify, search, structure tree by region and by type, layers, isolate, hide, X-ray, axial/coronal/sagittal sections, quiz (find it / name it), save image.
- Data sources, downloaded and built on your computer: BodyParts3D 4.3 (full resolution), BodyParts3D 4.0 (simplified) and Z-Anatomy (Latin names, definitions, lymphatics, fasciae). Several can be installed and switched.
- Mirrored copies of muscles that a source models on one side only (flagged, can be hidden), and side labels for unsided names.
- Offline definitions and Latin names from Z-Anatomy, also shown for BodyParts3D structures; Wikipedia summaries when online.
- Runs as a desktop app (Linux `.deb` / AppImage), in any browser from a local server, or as a static website (GitHub Pages) built by GitHub Actions.
- About page with lab information.

Development before the first public release went through internal versions 0.1-0.3.
